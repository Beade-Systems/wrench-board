The files under `vendor/parsers/` are unmodified BoardRipper source files.
Their paths and SHA-256 checksums are recorded in `upstream.json`.
BoardRipper is distributed under GNU AGPL version 3; the complete license is
in `LICENSE`. Upstream's complete attribution file is in `THIRD_PARTY.md`.
The Allegro implementation identifies KiCad 10's GPL-3.0 Allegro importer as
its source. Preserve these notices and licenses when distributing the code.

Local integration:

- `vendor/store/log-store.ts`: replacement for the UI logger; no UI dependency.
- `bridge.ts`: stdin binary → BoardRipper → stdout JSON; converts the net Map.
- `bridge.cjs`: bundled output, generated by esbuild 0.25.12, target Node 18.
- `../allegro.py`: subprocess boundary and mapping to Wrench Board models.

Rebuild from the repository root:

```
python3 scripts/build_allegro_bridge.py --esbuild /path/to/esbuild
```

All input sources are shipped; no downloads occur at runtime. Node 18 or newer
is required, selectable with `WRENCH_BOARD_NODE`. Imports have a 60-second
wall-clock timeout and a default 1024-MiB V8 heap limit (adjustable in Settings or `ALLEGRO_HEAP_MB`) (not a total-process RSS limit).
The Docker runtime installs Node through its distribution package manager.

Do not treat a subprocess boundary as removing license obligations. Before
redistributing or operating a modified combined application, comply with the
applicable AGPL/GPL source and notice requirements. This notice does not grant
rights to third-party board files; test samples stay outside the repository.

Mapping limitations: copper pours, standalone pad artwork and global
silkscreen paths are not represented in Wrench Board's current Board model.
Parts, pins/pad dimensions, net connectivity, traces, vias, outline and layer
names are retained. Upstream warnings and inferred-placement flags are retained;
the library marks inferred parts with amber dashed outlines. Version 15 is
experimental and receives a visible warning; zero-part/zero-pin results fail.
